# BeYourTools Keyword Strategy

Researched 2026-10-17. Method: web research on the free-online-tools niche + SERP pattern analysis.
Core insight: head terms ("pdf converter", "json formatter") are dominated by authority brands;
the winnable space is **long-tail, intent-rich queries** with modifiers:
**free / no signup / no watermark / online / in browser / no upload**.
The site's 100%-client-side architecture is itself a keyword angle ("no upload" queries
have low competition and rising demand as employers block upload-based tools).

Assessment scale — Volume: H/M/L · Competition: H/M/L · Intent: transactional (wants the tool now).

## Placement notes (integrated 2026-10-17)

- **Homepage**: title/description carry "free online tools … no signup"; H1 stays brand-focused
  (keyword stuffing the H1 would read as spam). Category descriptions use natural
  "free … in your browser" phrasing.
- **Category hubs** (/json-tools, /pdf-tools, /image-converter, …): meta descriptions
  include "free", "no signup", "no watermark" where true (all true site-wide).
- **Tool pages**: primary keyword in title + meta description; 1–2 long-tail variants
  answered naturally in the FAQ section (e.g. "Is there a file size limit?"-style
  questions matching real search phrasing). No stuffing, no misleading claims —
  every claim (free, no signup, in-browser) is verifiably true.
- **Blog**: posts target informational variants ("how to compress images for web",
  "what is pdf metadata") that funnel to tool pages via internal links.
- **Privacy angle**: "no upload" / "in your browser" phrasing doubled down across
  tool intros — low-competition differentiator vs iLovePDF-style upload tools.

## Maintenance

Revisit quarterly: check Google Search Console for impression growth on these terms,
promote winners (add internal links), drop losers. Watch for AI Overview coverage
on informational variants — tool pages with direct answers + FAQ schema are the
best defense.
